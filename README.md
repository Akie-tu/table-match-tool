# 电商工具 (Table Match Tool)

一站式电商工具：**表格核对 + 图片转换 + 数电发票批量开票生成**，GUI（tkinter）+ CLI 双界面，Windows 绿色单文件版双击即用。

> 场景：退货核对（快递单号→规格+数量）、批量图片转JPG、数电发票批量开票导入模板生成

---

## ✨ 功能总览

| Tab | 功能 | 一句话 |
|-----|------|--------|
| ① 表格核对 | 用A表字段检索B表回填 | 快递单号→规格商家编码+数量+多规格标记 |
| ② 图片转JPG | 批量图片格式转换 | webp/png/heic→jpg，保留目录树 |
| ③ 开票生成 | 数电发票批量开票 | 录入购买方→自动生成税务导入xlsx |

## ① 表格核对

用「源表」的某个字段（如快递单号）去「目标表」检索，回填需要的字段，支持一单多商品自动标记「多规格」。

### 功能点
- **任意检索键列**：快递单号 / 平台订单号 / 运单号 ... 完全可配置（按表头名找列，不写死坐标）
- **任意回填字段**：映射配置式（源列:目标列）
- **增量填充**：已有数据不覆盖（只填空白格）
- **多规格标记**：一个检索键对应 ≥2 种不同商品时，自动在备注列写「多规格」
- **多值兼容**：一个键对应多行/逗号分隔多单号
- **未匹配清单**：清晰列出没找到的键值

### GUI 用法
```
选择源表(被填的) → 选择目标表(数据源)
源表键列: 快递单号    目标表键列: 快递单号
映射: 规格商家编码 → 规格商家编码
映射: 数量 → 申请数
多规格判断列: 规格商家编码   备注列: 备注
→ 开始核对
```
结果：自动填规格+数量，一单多种商品时备注写「多规格」，已有数据不动，源文件不被修改（另存新文件）。

### CLI 用法
```bash
python table_match_tool.py 源表.xlsx 目标表.xlsx \
  --src-key "快递单号" --tgt-key "快递单号" \
  --map "规格商家编码:规格商家编码" \
  --map "数量:申请数" \
  --sku-col "规格商家编码" --remark-col "备注"
```

## ② 图片转JPG

批量把图片转成 JPG 格式，**保留原目录结构**输出。

### 功能点
- 支持格式：webp / png / heic / bmp / gif 等 → JPG
- **保留目录树**：源文件夹结构完整复制到输出目录
- 非图片文件自动复制（不转换）
- 质量可调（1-100，默认 92）

### GUI 用法
```
选择源文件夹 → 输出路径(可空=自动加"_jpg") → 质量 → 开始转换
```

## ③ 开票生成（数电发票）

按国家税务总局**数电发票批量开票导入模板**（V260401 版）生成可直接上传税务系统的 xlsx。

### 功能点
- **固定内容自动填**：发票类型(普通发票) / 是否含税(是) / 项目名称(滤芯) / 税收编码(1090130020000000000) / 单位(个) / 税率(0.01)，界面可改
- **流水号自动**：001、002、003… 基本信息表+明细表两表同步
- **自然人自动识别**：无税号（个人/海外）→ 受票方自然人标识自动填「是」
- **智能粘贴**：可从 Excel 整块复制直接粘贴（见下）
- **内置模板**：`invoice_template.xlsx`（官方模板 11 个 sheet 原样保留，字典表不动），也可自选模板
- **校验**：必填项/金额格式/税号格式生成前检查
- **备注**：写入模板 W 列（备注）

### 录入方式

**方式1：双击单元格手填**
- 表格每行 = 一张发票（流水号列自动只读）
- 双击任意单元格 → 就地输入 → 回车确认

**方式2：Excel 复制直接粘贴（推荐）**
- 在表格中 **Ctrl+V** 粘贴即可，智能识别列：

| 复制内容 | 自动去向 |
|---------|---------|
| 名称+税号（多列） | 名称列起对齐 |
| 金额+数量（两列数字） | 金额列+数量列（按小数/整数识别） |
| 金额单列（小数） | 金额列 |
| 数量单列（≤4位整数） | 数量列 |
| 订单号（>4位数字/长编码） | 备注列 |
| 文字单列 | 名称列 |

**方式3：点列精准粘贴（防串列）**
- **先单击目标列任一行** → 再 Ctrl+V → 数据只进该列（优先于自动识别）
- 例：点「备注」列 → 粘贴订单号 → 只进备注列

**方式4：单列粘贴→下拉手动指定**
- 工具底部「单列粘贴→」下拉：自动/名称/税号/自然人/数量/金额/备注，手动选择优先

### 生成
```
点「▶ 生成开票xlsx」→ 选保存位置 → 文件直接上传税务系统开票
```
生成的 xlsx：`1-发票基本信息`（每张发票一行）+ `2-发票明细信息`（每行商品）+ 全部字典 sheet 原样保留。

### 固定内容说明
顶部「固定内容」区可修改（默认已按滤芯业务配好，通常不用动）：
- 发票类型、是否含税、项目名称、税收编码、单位、税率
- 开票模板路径（默认内置模板）
