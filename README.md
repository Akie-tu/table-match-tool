# 通用表格核对工具 (Table Match Tool)

用「源表」的某个字段（如快递单号）去「目标表」检索，回填需要的字段，并支持一单多商品自动标记「多规格」。

> 电商场景：退货表(快递单号) → 售后处理明细 → 自动填 规格商家编码 + 数量(申请数)

## ✨ 功能

- **任意检索键列**：快递单号 / 平台订单号 / 运单号 ... 完全可配置
- **任意回填字段**：映射配置式（源列:目标列），不写死任何列
- **增量填充**：已有数据不覆盖（只填空白格）
- **多规格标记**：一个检索键对应 ≥2 种不同商品时，自动在备注列写「多规格」
- **多值兼容**：一个键对应多行/逗号分隔多单号
- **未匹配清单**：清晰列出没找到的键值
- **两种界面**：GUI（tkinter）+ CLI（命令行/交互）

## 📦 版本

| 文件 | 说明 |
|------|------|
| `table_match_gui.py` | **GUI版**（tkinter 标准库，Windows 原生） |
| `table_match_tool.py` | CLI/交互版 |

## 🚀 使用

### GUI 版
```bash
python table_match_gui.py
```
选择源表/目标表 → 填检索键列名 → 加回填映射 → 填多规格列 → 开始核对

### CLI 版
```bash
python table_match_tool.py 源表.xlsx 目标表.xlsx \
  --src-key "快递单号" --tgt-key "快递单号" \
  --map "规格商家编码:规格商家编码" \
  --map "数量:申请数" \
  --sku-col "规格商家编码" --remark-col "备注"
```

### 交互版（CLI 直接运行）
```bash
python table_match_tool.py
```
按提示输入路径和列名。

## 🖥 依赖

```
openpyxl
```
GUI 版需要 tkinter（Windows/Linux 自带）。

## 🎯 场景示例

**退货核对：**
```
源表键:  快递单号
目标表键: 快递单号
映射1:    规格商家编码 → 规格商家编码
映射2:    数量 → 申请数
多规格列: 规格商家编码
备注列:   备注
```
结果：自动填规格+数量，一单多种商品时备注写「多规格」，已有数据不动。
